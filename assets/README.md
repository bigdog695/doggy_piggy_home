# 资源文件说明

本目录需要放置以下图标/图片文件：

## 必需文件

1. `logo.png` - 应用Logo，尺寸建议为 144x144 像素
2. `user-avatar.png` - 用户头像占位图，尺寸建议为 80x80 像素
3. `ai-avatar.png` - AI头像图标，尺寸建议为 80x80 像素
4. `send-icon.png` - 发送按钮图标，尺寸建议为 40x40 像素

## 图标生成指南

可以使用在线工具生成所需图标：

1. 对于 logo.png：可以使用渐变色圆角矩形加上"AI"文字
2. 对于 user-avatar.png：可以使用简单的人物轮廓头像
3. 对于 ai-avatar.png：可以使用类似ChatGPT的绿色渐变图标
4. 对于 send-icon.png：可以使用简单的纸飞机图标

## 图标样式参考

为保持与ChatGPT风格一致，建议：

- 主色调使用 #10A37F (ChatGPT绿色)
- 背景色使用 #343541 (深灰色)
- 辅助色使用 #444654 (浅灰色)
- 文字颜色使用 #FFFFFF (白色)
